# Harken for macOS

Install [Harken](https://harken.hemisthia.com/) with Homebrew:

```sh
brew install hemisthia/tap/harken
```

Requires a Mac with Apple silicon and macOS 14 Sonoma or later. After installing, open Harken and sign in.

Harken updates itself. To update through Homebrew instead:

```sh
brew upgrade hemisthia/tap/harken
```

To uninstall:

```sh
brew uninstall hemisthia/tap/harken
```

Uninstalling removes the app and keeps your settings and content.

Already installed Harken from the website? You don't need Homebrew; Harken keeps itself up to date.

Help: [harken.hemisthia.com/support](https://harken.hemisthia.com/support/)
